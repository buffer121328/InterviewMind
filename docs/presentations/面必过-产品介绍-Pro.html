01 · WHY NOW

生成不等于可信

07 · CONTEXT ENGINE

RAG 负责“找得到”，Memory 负责“记得住”

ContextAssembler

来源分级、双层预算、确定性选择、截断、注入过滤和安全审计。

用户级隔离

Best-effort 降级

10 · OBSERVABILITY × EVALUATION

不只问“跑没跑完”，还要问“做得对不对”

OBS

统一观测事件

  • 模型、工具、检索、外部 IO、审批与护轨事件
  • 同一事实投影到 Langfuse、AgentRun 审计和 Eval Collector
  • 只记录摘要、耗时、计数和稳定错误分类
EVAL

真实 Agent Eval Harness

  • 生产入口适配器，而不是伪造输出
  • 确定性契约优先，Judge 作为补充
  • 数据集版本、人工标注、回归与发布门禁

12 · DESIGN EXCELLENCE

优秀设计，不是功能多，而是边界清楚

薄 API

路由只做协议和异常转换，业务逻辑进入可复用 Workflow。

Agent 与业务分离

Agent 负责推理与状态，Workflow 负责业务入口与持久化。

统一模型网关

超时、fallback、池调度与观测不散落在业务代码。

可恢复 Harness

长任务天然支持队列、进度、重试、恢复和事件流。

安全默认拒绝

不可信上下文、URL 和副作用工具均有明确 fail-closed 边界。

评测进入发布流程

失败案例沉淀为数据集，回归结果进入发布门禁。
