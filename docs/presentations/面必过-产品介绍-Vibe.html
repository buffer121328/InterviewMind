09
LEARN FROM EVERY RUN
一次运行完成，
不代表一次任务真正成功。面必过区分运行成功、语义成功与完全成功。模型、工具、检索、审批和护轨事件被统一记录；失败案例进入数据集、回归检测与发布门禁。
RUN

运行成功

流程是否走完，任务是否得到终态。

SEM

语义成功

答案是否正确，是否满足案例契约。

ALL

完全成功

质量、安全、审批和可观测性共同通过。

10
DESIGN PRINCIPLES

真正优秀的设计，
是让边界看得见。

01

事实有权威来源

业务结果、队列状态、检查点与外部镜像不互相冒充。

02

失败有恢复路径

长任务、模型、记忆与外部服务都有明确降级方式。

03

行动有人工边界

模型不能绕过后端审批、权限和投递确认。

04

上下文有预算

不是越多越好，而是来源可信、相关且安全。

05

观测保护隐私

记录摘要、计数和状态，不上传敏感正文。

06

评测进入发布

质量回归不依赖感觉，而由数据集和硬门禁管理。
